# Test instructions

For the store's reviewers. No test account is given: sign-up is open, and any public web page works. The Dashboard's Additional instructions field takes at most 500 characters, so the text below stays under that.

```text
No test account is needed: sign-up is open and new accounts get free credits.

1. Open any web page, for example a Wikipedia article.
2. Click the Webco icon: the side panel opens. Click "Sign in" (Google or an email code).
3. Ask "Summarize this page." Allow the site when Webco and then Chrome ask.
4. Ask "Search the web for today's top news." to try a web search.

Webco only reads: it changes nothing on any site.
```
