# Cofun

Cofun is a Chrome side panel for asking about an open tab, reading public pages, and searching the web. You can add tabs to a question or send selected text with the browser’s “Ask Cofun” menu.

To try the prototype, build it and load `extensions/cofun/dist` in Chrome as an unpacked extension. Set up its sign-in origin and hosted service using the [development guide](../../docs/development.md#extensions).

See [Cofun privacy](PRIVACY.md) for the data the extension uses.
