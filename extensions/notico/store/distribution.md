# Distribution

| Field | Value |
|---|---|
| Payments | Free of charge |
| Visibility | Public |
| Regions | All regions |

Version 0.1.0, the one in the store, sells nothing. The next version lets users buy credit packs through Stripe, so Payments becomes "Contains in-app purchases" in the Dashboard before that version is submitted.

Changing the visibility by hand means the next version must be published by hand once more, before the store's API could publish one again.
